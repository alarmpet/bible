# 다음 작품 주제 추천 (현대 허구 드라마)

> **작성:** 2026-08-09  
> **배경:** smoke_g1「한빛물산 계약직·동해패키지 횡령」은 소재 신선도가 약하고, 업로드 파이프 품질 이슈와 겹쳐 본선 부적합.  
> **원칙:** 허구 고지, 실명·실기관 금지, 약자 통쾌 or 가족 or 미스터리 중 채널 톤에 맞는 것 선택.

---

## 왜 이전 소재가 약했나 (짧게)

- “계약직 + 엑셀 이상 + 퇴사 권고 + 대표 비자금”은 **이미 많이 쓰인 공식**.  
- 증표가 서류·녹취 중심이라 **영상 비주얼 훅**이 약함 (모니터·봉투 반복).  
- 반전 2개(비자금 / 경호 회색)는 설계상 괜찮지만, **초반 후킹이 ‘사무실 일상’**이라 이탈 위험.

## 추천 TOP 6 (제작·영상 적합도 순)

### 1) ★ 추천 1위 — 「요양원 약 바구니 장부」
| 항목 | 내용 |
|---|---|
| 장르 | 약자 통쾌 + 제도 |
| 주인공 | 요양보호사 / 간호조무사 (가명 시설) |
| 훅 | 야간 근무 중 **투약 기록과 실제 약 개수**가 안 맞음 |
| 악 | 원장·총무의 “서류상 정상” 압박, 보호자 민원 떠넘기기 |
| 반전 | 아끼는 동료가 **조작 실행자**였거나, 원장이 아닌 **체인 본사 감사 라인** |
| 시각 | 약 카트, 손목 밴드, CCTV 사각, 야간 복도 — **컷 다양** |
| 주제 한 줄 | “사람을 지키는 기록이, 사람을 지우는 기록이 될 때” |
| 길이 추천 | 티어 A 15분 또는 B 25분 |

### 2) ★ 추천 2위 — 「학원 환불 거절 문자 한 줄」
| 항목 | 내용 |
|---|---|
| 장르 | 해학·응징 + 직장 |
| 주인공 | 학원 상담·행정 알바 / 학부모 |
| 훅 | “환불 규정 확인” 문자가 **다른 학부모 단체방에 공유**되며 폭발 |
| 악 | 원장·실장의 허위 커리큘럼·강제 카드 할부 |
| 반전 | 주인공이 쓰던 내부 양식 파일에 **원장 개인 계좌 메모** |
| 시각 | 상담실, 교재 탑, 카드 단말기, 단체 카톡 UI(연출) |
| 주제 한 줄 | “규정은 약자를 막기 위해 쓰이기도 한다” |
| 길이 추천 | A 12–15분 (템포 빠름, 업로드 친화) |

### 3) 추천 3위 — 「아파트 관리비 카톡방의 실종」
| 항목 | 내용 |
|---|---|
| 장르 | 미스터리·진상 (인간 비리 회수) |
| 주인공 | 신혼/전업 입주민 대표 당선자 |
| 훅 | 동대표가 갑자기 잠수 → 관리비 장부 USB만 남음 |
| 악 | 관리소장 + 특정 업체의 장기 수의계약 |
| 반전 | ‘실종’은 도피였고, 주인공 이웃이 묵인 측 |
| 시각 | 지하 주차장, 관리실, 택배 보관함, 옥상 — **공간 풍부** |
| 주제 한 줄 | “공동의 돈은 공동의 눈을 필요로 한다” |

### 4) 추천 4위 — 「배달 라이더의 블랙박스 10초」
| 항목 | 내용 |
|---|---|
| 장르 | 약자 통쾌 |
| 주인공 | 시간제 라이더 |
| 훅 | 사고 누명(과실 100%) — **블랙박스 10초**에 다른 차 끼어들기 |
| 악 | 보험 담당·가게 사장의 책임 전가, 플랫폼 콜 정지 |
| 반전 | 목격 영상이 가게 CCTV에 있었고 사장이 지웠다고 함 → 클라우드 백업 |
| 시각 | 빗길, 헬멧 캠, 교차로, 병원 대기 — **유튜브 클릭 강함** |
| 주제 한 줄 | “약자의 시간은 증거로만 되찾을 수 있다” |

### 5) 추천 5위 — 「엄마 통장에 찍힌 ‘효도비’」
| 항목 | 내용 |
|---|---|
| 장르 | 가족·유산 |
| 주인공 | 간병하는 둘째 딸/아들 |
| 훅 | 요양 비용 부족 — 큰집이 보내던 ‘효도비’가 **실제로는 엄마 명의 대출 이자** |
| 악 | 장남 부부 “엄마를 위해서” 반복 |
| 반전 | 엄마가 알고도 침묵한 이유(손주 학비) |
| 시각 | 병원 팔찌, 통장 도장, 빈 약봉투, 버스 환승 |
| 주제 한 줄 | “효라는 말이 장부를 덮을 때” |
| 주의 | 감성 과잉·혐오 자극 수위 조절 |

### 6) 추천 6위 — 「공장 하청 기술자의 ‘안전 리포트’」
| 항목 | 내용 |
|---|---|
| 장르 | 직장·조직 스릴러 |
| 주인공 | 하청 설비 기사 |
| 훅 | 위험 설비 리포트 올렸더니 **본인 징계** |
| 악 | 원청 관리자 + 하청 소장 유착 |
| 반전 | 사고 직전 문자 한 통, 안전모 캠 사진 |
| 시각 | 공장 라인, 스파크, 보호구, 야간 교대 — **강렬** |
| 주제 한 줄 | “침묵한 안전은 사고가 아니라 선택이다” |
