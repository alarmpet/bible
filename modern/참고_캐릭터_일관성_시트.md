# 참고: 캐릭터 일관성 · 다각도 시트 (v12 / Flow v6)

> **문제:** 장면마다 `image_gen`만 돌리면 얼굴·체형·복장이 흔들린다.  
> **원칙:** **한 장의 베이스(정면/3/4) → `image_edit` 체인으로만** 다각도·표정·복장 변주.  
> 정체성(IDENTITY)이 산출물이지, 예쁜 단독 컷이 아니다.

---

## 1. 필수 산출물 (캐릭터당)

주요 인물(주인공·악역·핵심 조력) **전원** 아래를 갖춘 뒤에야 본편 장면 대량 생성.

| 코드 | 뷰 | 용도 |
|---|---|---|
| **A0** | 베이스 3/4 또는 정면 (허리 위, 회색 배경) | 모든 edit의 원점 |
| **A1** | **정면** front | 표정·비율 기준 |
| **A2** | **측면** strict profile (코·가슴이 프레임 가장자리 방향) | 옆모습 장면 |
| **A3** | **후면** back (머리·어깨·복장 실루엣) | 뒤통수·퇴장 장면 |
| **S0** | **턴어라운드 시트** (한 장에 A1+A2+A3 가로 배열) | Flow/레퍼런스 첨부용 권장 |
| **E1~E3** | 표정 3종 (평정 / 압박 / 결의 등 역할별) | 감정 컷 일관성 (주인공·악역 필수) |

조연(기능 1~2회): A0 + S0 최소. 단역: 앵커 텍스트만.

---

## 2. 앵커 락 (텍스트 · 이미지 공통)

장면 프롬프트·edit 프롬프트 **매번** 동일 구 유지.

```
[국적·연령대] [역할]
outfit: <상의·하의 분리, 색·상태>
hair: <길이·가르마·색>
face: <얼굴형·눈·특징 1~2>
body: <키·체형 한 줄>
style: refined webtoon manhwa, clear bold line art, flat cel-shaded coloring
```

**금지:** 장면마다 복장 색·머리 길이 즉흥 변경.  
**변화 시:** 별도 버전 코드 (예: `youjin_A0_winter_coat`) + 새 베이스.

---

## 3. Edit-chain 프로토콜 (Imagine)

```
1) image_gen → A0 베이스 (회색 배경, 단독, 중립 표정)
2) image_edit(A0) → A1 정면   "Keep this exact character — same face, hair, outfit, proportions, style. Change ONLY camera to full front view..."
3) image_edit(A0 또는 A1) → A2 측면  strict profile
4) image_edit(A0 또는 A1) → A3 후면
5) image_edit 멀티레프 또는 합성 → S0 턴어라운드 시트
6) image_edit(A1) → E1/E2/E3 표정만 변경 (포즈·배경·복장 고정 선언)
7) 본편 장면: image_edit( S0 또는 A0+A1 ) + 장면 지시
   ★ 본편을 image_gen 단독으로 다시 뽑지 말 것 (일관성 붕괴 1순위 원인)
```

### 프롬프트 고정 문구 (edit 맨 앞)

```
Keep this exact character identity: same face shape, eyes, haircut, hair color,
body proportions, outfit colors and design, webtoon manhwa line art and flat cel shading.
Change ONLY: <각도/표정/배경/동작 중 하나>.
Neutral gray seamless background for sheet views. No text no watermark.
```

### 측면·후면 검증

| 뷰 | 합격 조건 |
|---|---|
| 측면 | 코·턱·가슴이 **한 방향**, 정면 비스듬 금지 |
| 후면 | 얼굴 없음 또는 귀·후두부만, 복장 뒷판·머리 실루엣 일치 |

비대칭(안경·시계·가르마): **뷰어 기준** 좌우 표 작성 후 각 뷰 검증 (game-character-consistency).

## 4. 본편 장면 생성 규칙

| 순위 | 방법 |
|---|---|
| 1 | `image_edit` + **S0 또는 A0+해당 각도에 가까운 뷰** |
| 2 | 2인 장면: 두 캐릭터 각각의 A0/S0를 multi-ref |
| 3 | (비권장) text-only `image_gen` — 응급·배경만 |

장면 프롬프트에도 앵커 3요소를 텍스트로 재기재 (모델이 레프를 무시할 때 보험).

## 6. 검증 체크리스트 (캐릭터 세트 완료 전)

- [ ] A0 존재, 회색 배경, 타 인물 없음  
- [ ] A1/A2/A3 또는 S0 — 같은 머리·복장·체형  
- [ ] 측면이 진짜 프로필인가  
- [ ] 시계·안경·가르마 좌우 일관  
- [ ] 주인공·악역 표정 3종  
- [ ] 본편 컷이 edit-chain 경유인가 (gen 단독 비율 기록)

실패 시: **해당 뷰만** base에서 재edit. 세트 전체 재생성 금지.

---

## 7. Flow / 외부 툴 연동

- Flow ingredient: **S0 턴어라운드** 또는 A0+A1 우선 업로드  
- v6 STEP1 UPLOAD 문구는 A0용. 다각도는 STEP1.5로 본 문서 적용  
- 구 v5.2 “턴어라운드 폐지”는 **ingredient 슬롯 절약** 맥락이었음.  
  **일관성 목적의 다각도 시트는 v6에서 의무 복구.**
