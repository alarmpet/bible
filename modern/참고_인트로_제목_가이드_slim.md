# 참고 3(slim): 인트로·제목 가이드 (현대 v12)

## 제목 6패턴 (골격 유지, 예시만 현대)

| 패턴 | 예시 |
|---|---|
| 충격 행동 + 반전 궁금증 | 역 앞 편의점에서 아이를 데려간 여자, 12년 뒤 그 아이의 정체는? |
| A vs B 대비 | 큰아들은 아파트를 가졌고 막내는 어머니를 모셨다 |
| 상황 + 미완성 반응 | 임원 면접에 작업복으로 나타난 여자, 모두 비웃었는데… |
| 은혜 행동 + 결과 봉인 | 쓰러진 노인을 살린 택배 기사, 사흘 뒤 회사로 찾아온 여자 |
| 의외의 선택 | 억대 합의금 대신 녹취 파일 하나를 고른 남자 |
| 시간 점프 | 고시원 청년을 거둔 식당 주인, 10년 후 그 가게 앞에 선 남자 |

**SEO 꼬리 (기본):** ` | 반전 드라마 감동 사연` 또는 장르별  
**금지 기본값:** `실화` 단어 — 별도 승인 시에만. 승인 시에도 허구 고지 유지.  
**숫자 권장:** 억·년·층·살 중 1개+.

## 인트로 자가검증 5문항 (하나라도 "예"면 폐기)

1. 결말 짐작 가능?  
2. 숨겨진 정체·관계 노출?  
3. 진범·흑막 감?  
4. 갈등 해결 암시?  
5. 제목 행동의 왜·어떻게·누구·결말 노출? (행동 자체 1문장 허용)

## 인트로 6문장 (200~350자)

| 문장 | 룰 |
|---|---|
| 1 | 큰따옴표 파격 대사. 날것 감정. 숫자·물건·조건 |
| 2~4 | 지금 이 순간만. 결과·결말 금지. **연도·장소·직업 앵커를 한 문단에 몰지 말 것** |
| 5 | "그런데" — 열린 궁금증. 닫힌 질문 금지 |
| 6 | 고정: "구독과 좋아요는 더 좋은 이야기를 만드는 힘이 됩니다. 그럼 지금부터..." |

닫힌 질문 ❌ `"과연 그는 친아들이었을까요?"`  
열린 ✅ `"그런데 이 봉투에는 아무도 모르는 사연이 하나 들어 있었습니다."`

## 위해 흔적 (한 단어·시각물)

압류 딱지 / 진단서 / 녹취 파일 / 퇴사 권고 / 산소호흡기 / 빨간 봉투 / 차단 메시지 / 수배 전단(가명) …

## Good 예시

**약자 통쾌**
"이번 달 말까지 나가지 않으면, 네 경력 증명서에 뭐가 찍힐지 알겠지."
2019년 겨울, 서울 한 중소기업 회의실에서 계약직 직원이 서류 봉투를 받아 들고 있었습니다.
봉투 모서리가 구겨져 있었고, 손가락 끝이 하얗게 질려 있었습니다.
그런데 그 봉투 안에는 사장도 모르는 파일 하나가 더 들어 있었습니다.

**미스터리**
"병실 CCTV는 어젯밤에 끊겼습니다. 그런데 약 카트 자물쇠는 안에서 잠겨 있었습니다."
수간호사의 손이 차트 위에서 멈췄습니다.
복도 끝 비상구 표지판만 파란빛을 깜빡이고 있었습니다.
그런데 이 밤의 기록에는 약보다 더 위험한 빈칸이 하나 남아 있었습니다.
