## 비트별 룰 (현대)

| 비트 | 핵심 룰 |
|---|---|
| ① 오프닝 | **`"20○○년, [동네·시설]에서…"`** 또는 `"그해 [계절], ○○시…"`. 주인공 외적 상태+결핍. ⑮와 대척. **옛날 옛적 금지.** |
| ② 주제 명시 | 누군가 주제 대사. 주인공 무시·이해 못함. 문체: 구어 잠언(`~는 법이다` 등). `~느니라` 기본 금지 |
| ③ 설정 | 현대 루틴 2장면(출퇴근·알바·면회·독촉 등)+인물+약점+악역 암시. 직업 업무·권한 1개씩 비춤 |
| ④ 기폭제 | 외부 결정적 사건. 일상 붕괴 |
| ⑤ 토론 | 저항·만류·부추김 |
| ⑥ 2막 진입 | 돌이킬 수 없는 능동 결정 |
| ⑦ B스토리 | 조력자 유대. 독자 목표·거절 조건. 3막 씨앗 |
| ⑧ 재미와 놀이 | 에피소드 카드 4~6. 장소·상대 분산(같은 로비 2↓). 각 편에 정보·선택 변화 |
| ⑨ 중간점 | 가짜 승리 또는 가짜 패배 |
| ⑩ 악당 역습 | 3단계: 약점 파악→이간·동맹 공격→최후 수단. 악역 **합리적 이익+넘지 않을 선** 명시 |
| ⑪ 절망 | 무언가 죽음(관계/자격/상징). **선택의 대가** 행동 |
| ⑫ 어두운 밤 | 깨달음 설명 금지 우선 → 대가 치른 뒤 ② 회상 |
| ⑬ 3막 | A+B 결합. B 교훈이 열쇠 |
| ⑭ 피날레 | 5단계: 대면→진실증명(증거 카드 경로)→악역몰락→형벌→보상. 관중=가족·동료·법정·여론 |
| ⑮ 마지막 | ① 대척. **관찰 가능 변화**(직업·관계·공간 사용) |
| 엔딩 | ② 변형 1~2문장 + 고정 마무리 |

## 2시간 strict 핵심

- ⑧ 에피소드 6+, 각 도입→시련→마무리, 장소·상대 다르게
- ⑩ 3단계 독립 장면, 단계 사이 장소·시간 전환
- ⑭ 5단계 각 충분 분량, 진실증명은 심어 둔 증거만

## 고정 마무리 멘트

```
다음 영상을 빠르게 만나보시려면 좋아요와 구독을 눌러주세요.
지금 화면에 나오는 더 재미있는 영상들도 함께 해주세요.
그럼 모두 행복한 하루 보내세요. 감사합니다.
```

## 챕터 분할

**1.5시간 (35,000자, 7챕터, 디폴트):** 1[인트로~②] / 2[③] / 3[④~⑥] / 4[⑦~⑧전반] / 5[⑧후반~⑨] / 6[⑩~⑪] / 7[⑫~엔딩]

**1시간 (25,000자, 5챕터):** 1[인트로~②] / 2[③~④] / 3[⑤~⑧전반] / 4[⑧후반~⑩] / 5[⑪~엔딩]

**2시간 (46,000자, 9챕터, strict):** 레거시와 동일 분할. 챕터 바닥 4,410자.

| 스토리 챕터 | 이미지 밀도 | 이유 |
|---|---|---|
| **1** (인트로~② 구간) | **고밀도** — 문장·대사·훅 단위 | 초반 이탈 방지 |
| **2 이후** | **사건 밀도** — 장소·사건 전환 단위 | 기존 방식 유지 |

## 장르 체크리스트

- **약자 통쾌:** 굴욕 2+ / 증거 증명 / 악역 음모 3단계+
- **가족·유산:** 말할 수 없는 한 문장(관계별) / 상징물 3회+ / 화해 또는 단절의 관찰 변화
- **직장 스릴러:** 내부 문서 경로 / 승진·평가 압력 / 측근 배신
- **미스터리:** 단서 3+(1 미스디렉션) / 용의자 3+ 동기 / 추리 관찰→가설→검증
- **사랑·재회:** 약속 물건 3+ / 장벽(빈부·질병·이민)
- **해학·사기:** 속임수 단계 / 호구 과정 / 통쾌 반전
- **도시괴담:** 옵션. 분위기+선택. 기본 OFF
