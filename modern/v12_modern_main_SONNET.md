아래 규칙은 기존 단계의 장르·분량·검수 지시보다 우선한다.

1. `memory/portfolio_state.json`의 최근 20편 Story/Execution DNA를 감사한다.

3. `truth_mode`를 확정한다. `TRUE_VERIFIED`와 `TRUE_PERMISSIONED`는 승인된 `source_packet` 없이는 진행 금지다.
4. Case B는 서로 다른 주제 카드 8개를 만들고 상위 3개의 차별성·실패 위험을 비교한 뒤 1개만 승인한다.
5. 시퀀스 ID와 Execution DNA(POV·시간구조·정보 비대칭·장면 엔진)를 먼저 정한다.
6. 캐릭터는 욕망 네트워크, 반전은 `clue_ledger`, 작품 계약은 `templates/project_contract.yaml` 형식을 사용한다.

8. 합본은 `python modern/scripts/audit_story_quality.py --text ... --contract ...`를 통과해야 렌더 단계로 간다.
9. 목표 분량 미달 시 반복문장으로 늘리지 않는다. `INSUFFICIENT_STORY_MATERIAL`을 반환하고 구조를 재설계한다.

python name_picker.py [계층] [남|여] --used [이미정한이름…] --n 6

취약=자동 선량 금지.

### 4-C: 줄거리 + 역할 분해 6칸 + 감동

부록 3.

1. 발단·갈등·결말 + 현실성 등급

3. **역할 분해** → **6칸 요약 표** (사용자 확정용)

5. 태그 분산 (한 태그 4+ 금지)

### 4-D: story_facts.md

부록 7. contract/matrix/evidence/beat에서 **파생**.  
나이 산수·시간순·사전지식 검증 → 통과 시 5단계.

### 5단계: 길이 + thumbnail_brief

`config/duration_matrix.yaml`에서 이야기 크기에 맞춰 선택한다.

- `quick` 15~25분: 한 관계·한 선택·한 핵심 반전
- `standard` 25~45분: 기본값, 주 플롯 + 얕은 보조선 1개
- `deep` 45~70분: 독립 욕망 보조선 1~2개
- `special` 80~120분: 승인 조건을 충족한 대형 단일 이야기
- `anthology` 총 80~120분: 25~35분 이야기 3편

사용자 무지정 → `standard`에서 목표 분을 제안한다. 100분은 기본값이 아니다. `special`은 보조선 2개, 목표 상태 변화 3회, 독립된 3막, 10분 파일럿, 반복 QA 통과가 모두 필요하다.
직후: progress 생성 → thumbnail_brief(부록8, 허구 고지 포함) → contract+facts+brief 전달 안내 → 6단계.

### 6단계: 챕터 작성 (1개/턴)

**로딩:** progress + 직전 끝 300자 + 이번 비트 행 + 관련 인물·증거 행만.  
전체 참고 파일·facts 통재로딩 금지.

**작법 닻**
- 리듬 3장치, 대사 40% 겨냥, 한 문장 한 호흡, 글자수 여유  
- **장면 6문:** 장소감각 / 선택압력 / 정보비대칭 / 숫자 / **정보 변화** / **선택지 변화**  
- 5·6 없으면 축약 후보  
- ⑧ 에피소드 카드 줄 유지  
- ⑪⑫: 대가 행동 우선  
- era_leak 자가 스캔  
- 동일 비대사 문장 3회·3문장 블록 재등장·기계적 분량 확장 금지  

**검증 경량:** 글자수 바닥 / 따옴표 / 한자 / era_leak(WARN).  
글자수 미달 → 장면 1개 추가 1회만. 그 외 1회 후 잔존 → 합본으로.
