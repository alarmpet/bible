# 참고 2(slim): 캐릭터·말투·문체·증표 (현대 v12)

> **1차 설계는 character_matrix(욕구·금기·전략·변화).**  
> 아래 말투 표는 **강도 조절 참고**일 뿐, 인물 유형을 고정 가면으로 쓰지 말 것.

## 캐릭터 설계 우선순위

1. 외적 목표 / 내적 결핍 / 핵심 가치 / 금기  
2. 압박 반응 / 정보 전략 / 변화 증거(행동)  
3. 직업 4요소(업무·권한·피로·윤리 딜레마)  
4. 그다음 말버릇·어미·호칭  

주요 3인: 이름표 가려도 화자 추정 가능해야 함.

## 말투 강도 참고 (고정 금지)

| 상황 | 경향 | 특징 |
|---|---|---|
| 주인공 평상 | ~요 / ~습니다 혼용 | 짧고 담담, 욕구는 대사에 |
| 악역(권력) | 반말 하향 또는 차갑 존대 | 협박은 **숫자·조건·기한** |
| 악역(교양) | 높임말 유지 | "그렇게 하시죠", 돌려 까기 |
| 조력 중장년 | ~지 / ~예요 | 깊이, 거절 조건 있음 |
| 청년 | 자연 구어 | 유행어 과다 금지(시니어 채널) |
| 구경꾼 | 수군 | "그러게", "그게 말이 돼?" |
| 추리 측 | 질문형 | 가설→검증 |

나이·지역 사투리는 **강도값**으로만. 모든 노인이 사투리일 필요 없음.

## 비하 호칭 (최대 2회)

`~년` 등 전체 최대 2. 위압은 **구체 위협·행동**으로.  
대체: "네 따위가", "가만히 안 둬", "각오해", 직급 내려 깔기.

## 나레이션 문체

- 기본: `~습니다` ↔ `~지요` 교차  
- 장치1: 나레이션 500자 연속 금지 → 대사 삽입  
- 장치2: 수사 질문 10문장당 ~1  
  - "그런데 이게 말이 됩니까?" / "그 순간 지훈의 손이 멈췄습니다."  
- 장치3: 짧은 전환 — "그때였습니다." / "문자가 울렸습니다."  
- ~습니다 3연속 금지. 어미 인접 3연속 금지  
- 문장 15~25자 권장(TTS)  
- 고풍 수사 하향 → 생활 감각 (소독약 냄새, 엘리베이터 소음, 알림음)

## 전문용어

시니어 청취: 첫 등장 시 **1줄 풀이**.

## 증표 풀 (복합 2유형+)

| 유형 | 예 |
|---|---|
| 문서 | 가족관계증명, 유언, 보험 수익자, 입양 기록 |
| 디지털 | 녹취, 메신저, CCTV, 이체, 위치 |
| 신체 | 흉터, DNA, 지병 기록 |
| 물건 | 사진, 목걸이 반쪽, 열쇠, 통장 사본 |
| 기억·습관 | 자장가, 요리법, 말버릇 |
| 공적 기록 | 학적, 군, 가명 기관 기록 |

**모든 핵심 증표는 evidence_cards에 접근 경로·시점 필수.**
