# plot_4c.md

## 제목
병동 CCTV가 끊긴 밤, 약 카트는 안에서 잠겨 있었다 | 반전 드라마 미스터리 사연

## 설정
- 발단: 야간 간호사 강수빈 근무 중 CCTV 끊김, 약 카트 이상, 투약 기록 공백
- 갈등: 간호부장 윤혜숙이 수빈 과실로 몰아 감사 전 약 재고 구멍을 덮으려 함
- 결말: 단절 로그·사각 동선·불출 대장·지시 메시지로 유용·조작 입증
- motif: D 명판결·추리[정보] + K 내부고발 요소[권력]

## ② 주제
"화면은 거짓말을 안 해요. 다만 끊기는 순간, 사람이 끼어듭니다."

## 역할 분해
- R1 [정보][권력] 혜숙이 감사 전 마약류 불출 구멍을 병동 사고로 위장
- R2 [관계] 상훈은 단순 기술자가 아니라 단절 구간에 ‘점검’ 핑계로 손을 댄 회색 목격자
- T1 내부 종결·징계 감면 미끼
- T2 메신저로 기록 인멸 지시(선 위반)
- C 로그·대장·사각·메시지
- M1 초반 수빈 단독 과실 프레임

## 6칸 요약
1. 약 구멍 위장 (R1) 2. 상훈 회색 (R2) 3. 내부 종결 미끼 (T1) 4. 인멸 지시 (T2) 5. 교차 증거 (C) 6. 과실 누명 (M1)

## 감동 행동
1. 수빈이 경위서 대신 타임라인 작성
2. 상훈이 도면을 내밀며 이름 빼 달라 함
3. 수빈이 감면 서류 밀어냄
4. 회의에서 메시지 공개
5. 승현이 추측 없이 시계만 물음
6. ⑮ 같은 복도, 다른 발걸음
