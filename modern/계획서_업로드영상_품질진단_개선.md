## 1. 사용자 이슈 ↔ 증거

### 1-A. 이미지 무의미 전환 (최우선)

**체감:** 앞부분에서 컷이 계속 바뀌는데 장면 의미가 없다.

**증거**

1. fulltext 배정 코드 (`build_shot_plan_json.py` → `build_smoke_g1_fulltext`):

```python
rel, title = imgs[i % len(imgs)]   # 챕터 이미지 리스트를 순서대로 순환만 함
```

2. Ch1 실제 시퀀스 (48씬 / 이미지 16장):

| 순서 | 이미지 | 나레이션 요약 | 의미 일치 |
|---|---|---|---|
| 1 | meeting_line | 기철 퇴사 권고 대사 | △ (회의 톤) |
| 2 | fluorescent | **봉투·볼펜** 설명 | ❌ |
| 3 | envelope_pen | **USB·2022 가을** | ❌ |
| 4 | envelope_hand | **한빛물산 외관·공단** | ❌ |
| 5 | usb_hook | **셔터·유진 소개** | ❌ |
| 6 | company_exterior | **어머니 수술·첫 출근** | ❌ |
| 7 | youjin_intro | **인사 담당 대사 3줄** (HR) | ❌ (유진 얼굴 컷) |
| 9 | gyeongho_late | 경호 대사인데 앞 인용은 **youjin 배정** | ❌ 이중 오류 |
| 17 | meeting_line **재등장** | 기철 복도 대사 | 순환 반복 |
| 18 | fluorescent **재등장** | 경호·커피 장면 | ❌ |

3. 챕터별 이미지 스위치율 (연속 씬에서 이미지가 바뀌는 비율):

| 챕터 | 씬 수 | 고유 이미지 | switch_rate |
|---|---|---|---|
| 1 | 48 | 16 | **1.00** |
| 2–5 | 44–49 | 6 | **1.00** |

→ **거의 매 나레이션 블록(~10–15초)마다 컷 강제 전환.**  
→ 40장으로 233씬을 채우면서 “순서만 돌리는” 방식이라 **스토리 비주얼 연출이 아님.**

4. 키워드 적합도 샘플 (앞 ~80씬, 알려진 키 있는 컷):  
   **fit_ok 10 / fit_bad 51 → 불일치 비율 ~0.84**

**결론:** 사용자는 착각한 것이 아니다. **이미지 선택이 대본 의미를 보지 않는다.**

### 1-B. 남자 캐릭터에 여자 목소리

**체감:** 남자인데 여자 목소리가 난다.

**증거 — 화자 배정 버그**

`guess_segments()` 핵심 분기 (발췌):

```python
elif any(k in text[...] for k in ("유진", "한 씨")) or True:
    #                                      ^^^^^^^^
    # or True → 앞 분기에 안 걸리면 무조건 youjin(F2)
    speaker = "youjin"
```

**`or True` 때문에 인용 대사 기본값이 사실상 유진(F2).**

감사에서 잡힌 **남성 역할 라인이 youjin으로 간 사례 (일부):**

| order | 배정 | 실제 화자 추정 | 대사 일부 |
|---|---|---|---|
| 9 | **youjin** | 경호(M) | “한 씨, 오늘도 남아요?” |
| 10 | **youjin** | 경호(M) | “몸이 먼저예요…” |
| 13 | **youjin** | 시우(M) | “페이퍼상으로는 이미 정리됐습니다.” |
| 17 | gicheol | 기철 맞음 / 단 “대표님, 목표치—”는 부하 발화 가능 | 혼선 |
| 18 | **youjin** | 유진이 아니라 **경호→유진 교차 오배정** | “어머니는 좀 어떠세요?”=경호 |
| 53, 68, 73, 74, 99… | **youjin** | 시우/기철 | “페이퍼상”, “서로 좋게”, “서명만” |

세그먼트 집계:

| speaker | 세그먼트 수 | voice |
|---|---|---|
| narrator | 260 | M2 |
| **youjin** | **251** | **F2** |
| gicheol | 45 | M5 |
| siwoo | 31 | M1 |
| gyeongho | 27 | M3 |

→ 인용 대사의 상당수가 F2로 쏠림. **남성 캐릭터 발화가 여성 보이스로 합성된 구간이 다수.**

**결론:** TTS 엔진 문제가 아니라 **화자 태깅 파이프 버그 + 약한 refine.**

### 1-C. 나레이션과 캐릭터 목소리가 비슷함

**voice_map 현재**

| speaker | voice | speed | filter |
|---|---|---|---|
| narrator | **M2** | 1.05 | 없음 |
| youjin | F2 | 1.08 | 없음 |
| gicheol | **M5** | 0.95 | 없음 |
| gyeongho | **M3** | 0.98 | 없음 |
| siwoo | **M1** | 1.15 | 없음 |

- SuperTonic **남 4 / 여 1**. 남성은 프리셋 번호만 다름.  
- pitch/EQ/reverb 등 **후처리 필터 미적용**.  
- speed 차이도 0.95–1.15로 **귀로 구분 어려운 구간 존재**.  
- 나레이션(M2)과 경호(M3)·기철(M5)이 특히 혼동 가능.

**결론:** “비슷하다”는 피드백은 **설계상 예상 가능**. multi-voice 플래그만 있고 **청감 분리 스펙이 없음.**

## 2. 목표 제품 정의 (재작성)

### 2-A. 업로드 “제대로”의 정의

| 축 | 합격 기준 |
|---|---|
| **의미 컷** | 각 씬 이미지(또는 홀드)가 해당 나레이션의 **장소·인물·소품·행위** 중 1개 이상과 일치 |
| **화자** | 인용 대사 speaker 정답률 ≥ **95%** (수동 샘플 50발화 기준) |
| **보이스 분리** | 나레이션 ≠ 전 캐릭터 청감 구분 가능 (blind A/B 5문항 중 4 이상) |
| **성별 일치** | 남성 캐릭터에 F 보이스 **0건** (자동 BLOCK) |
| **컷 리듬** | Ch1 고밀도여도 **의미 없는 강제 스위치 금지**. 같은 의미 구간은 홀드 허용 |
| **길이** | 15–25분 권장 티어 **또는** 50분 전문 티어 — 티어를 문서에 고정 후 제작 |
| **허구 고지** | 오프닝 유지 |

### 2-B. 권장 제품 티어 (택 1 후 고정)

| 티어 | 길이 | 대본 | 컷 수 | 용도 |
|---|---|---|---|---|
| **A. 스토리 완전 압축** | 12–18분 | 15비트 전부 + 핵심 대사 | 48–72 | 유튜브 유지율 우선 |
| **B. 준전문** | 25–35분 | 챕터 핵심 문단 + 전 대사 | 80–120 | 균형 |
| **C. 전문** | 45–55분 | chapter 전문 | 120–180 | 현재 의도, **이미지 대량 추가 필수** |

**권장:** 먼저 **티어 A 또는 B**로 “의미 맞는 업로드본” 확보 → 이후 C.  
(지금 C를 이미지 40장으로 돌린 것이 실패 원인.)

## 4. 개선 계획 (구현 순서)

### Phase 0 — 기준 고정 (0.5일)

1. 제품 티어 **A/B/C 확정** (사용자 결정).  
2. 완료 정의 체크리스트를 HANDOFF·validator에 반영.  
3. 현재 `upload/` 산출물은 **draft / 실패본**으로 라벨 (배포 금지).

### Phase 1 — 화자·보이스 수정 (1일) ★ 최우선

| 작업 | 내용 |
|---|---|
| 1.1 | `guess_segments`에서 **`or True` 삭제**. 미확정 인용은 `speaker=unknown` → 나레이션 fallback 또는 수동 큐 |
| 1.2 | 화자 배정 규칙 강화: **뒤에 오는 서술 주어** 활용 (“~가 물었습니다”, “시우가 말했다”) |
| 1.3 | 라인 사전(lexicon): 기철/시우/경호/유진 고정 대사 패턴 → speaker 강제 |
| 1.4 | `validate_job` BLOCK:  
  - `youjin` 세그에 남성 고정 패턴  
  - 남성 speaker에 F* voice  
  - unknown 비율 상한 |
| 1.5 | voice_map v2:  
  - narrator: **M2 + 낮은 pitch/느린 speed** 또는 전용 톤  
  - youjin: **F2** 유지  
  - gicheol: **M5 + 느림 0.9**  
  - gyeongho: **M3**  
  - siwoo: **M1 + 빠름 1.2**  
  - 가능 시 가벼운 EQ/고역 차이 문서화  
| 1.6 | 5보이스 미리듣기 재생성 → **`preview_approved: true` 필수 게이트** |

**완료 조건:** 샘플 50 인용 발화 정답 ≥95%, 남성→F 0건.

### Phase 2 — 이미지·의미 결합 (2–4일) ★ 체감 핵심

| 작업 | 내용 |
|---|---|
| 2.1 | **라운드로빈 폐기.** 배정 알고리즘 교체: |
| | a) 씬 텍스트에서 태그 추출 (장소/인물/소품/행위) |
| | b) 이미지 메타 태그 매칭 (파일명 + `images/INDEX.md` + shot title) |
| | c) 매칭 실패 시 **직전 의미 컷 홀드** (강제 스위치 금지) |
| 2.2 | Ch1: 문장/소품 단위 컷 유지하되, **같은 태그 연속이면 동일 이미지 유지** |
| 2.3 | Ch2+: 사건 단위 1–2컷. 나레이션만 이어지면 **홀드 + 약한 모션** |
| 2.4 | 이미지 갭 리스트 자동 출력 → 부족한 태그별 **추가 생성 우선순위** |
| 2.5 | (티어 C일 경우) 목표 고유 컷 **≥ 씬 수의 50%** 또는 홀드 정책 명문화 |

**완료 조건:** 감사 스크립트 키워드 fit_bad 비율 **≤ 0.20**, switch_rate **≤ 0.55** (ch1), 연속 무의미 순환 0.

### Phase 3 — 샷 플랜 재설계 (1–2일)

| 작업 | 내용 |
|---|---|
| 3.1 | 티어에 맞는 `build_shot_plan` 프로필: `upload_story` / `upload_fulltext_v2` |
| 3.2 | 패킹: 장면 경계(빈 줄·장소 전환·화자 전환) 우선, 글자 수 등분은 금지 |
| 3.3 | 씬 수 상한: 티어 A ≤ 72, B ≤ 120, C ≤ 180 |
| 3.4 | 각 shot에 `visual_tags[]`, `speaker_plan[]`, `hold_from_prev` 필드 추가 |

### Phase 4 — 재합성 파이프 (1–2일)

1. shot_plan 재생성 → pack `upload_v2` (기존 upload 덮지 않음).  
2. multi-voice TTS (수정 voice_map).  
3. lock → Hermes 렌더 → intro.  
4. **QA 게이트 통과 전 파일명에 `draft` 유지.**

### Phase 5 — QA 게이트 (자동화)

`validate_job` / 신규 `qa_upload_readiness.py`:

| 코드 | severity | 조건 |
|---|---|---|
| SPEAKER_GENDER_MISMATCH | BLOCK | 남성 speaker + F voice |
| SPEAKER_DEFAULT_YOUJIN_SPIKE | BLOCK | youjin 인용 비율 > 임계 (티어별) |
| IMAGE_SEMANTIC_FIT | BLOCK | 샘플 fit_bad > 20% |
| IMAGE_ROUND_ROBIN_PATTERN | BLOCK | 단순 순환 패턴 감지 |
| VOICE_PREVIEW_APPROVED | BLOCK | preview_approved != true |
| NARRATOR_VOICE_COLLISION | BLOCK | narrator voice ∈ character voices |
