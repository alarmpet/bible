## 3. 대본 구조의 정량 패턴

30편 평균은 다음과 같다.

| 항목 | 관찰값 | Human Archive에 주는 의미 |
|---|---:|---|
| 영상 길이 | 19.483분 | 18~20분 장편을 유지해도 충분히 빠른 시각 리듬이 필요하다. |
| 공백 제외 자막 글자/초 | 5.063 | 글자 수만으로 샷 수를 정하지 말고 실제 TTS 시간을 사용해야 한다. |
| 추정 문장/분 | 12.679 | 약 4.7초마다 문장 경계가 나타나며 한 화면은 대체로 1~2문장을 담당한다. |
| 문장 중앙값 길이의 영상별 평균 | 28.1자 | 한 문장 안에 하나의 주장이나 반전이 들어가는 경우가 많다. |
| 질문/분 | 0.576 | 질문은 계속 남발하지 않고 훅과 전환 지점에 배치한다. |

첫 60초 훅에서는 질문 73.3%, 시간·숫자 앵커 76.7%, 상식 뒤집기 63.3%가 관찰됐다. 시청자를 직접 부르는 표현은 16.7%뿐이었다. 즉 진행자의 친근한 말투보다 **구체적 숫자·시대, 풀리지 않는 질문, 예상과 반대되는 결과**가 훅의 중심이다.

30편 전체에서 `그런데` 289회, `하지만` 95회, `왜` 76회가 검출됐다. 대표 서사 루프는 다음과 같다.

```text
관찰 가능한 사실·통념
→ 시청자가 예상할 설명
→ 그런데/하지만 반전
→ 원인·증거·메커니즘
→ 더 큰 함의 또는 다음 질문
```

시각은 이 루프를 따라 `전경→행동→세부 증거→지도/도식→다시 넓은 전경`처럼 규모를 바꾼다. 같은 유형의 화면이 오랫동안 연속하지 않는다.

## 4. 이미지 매칭의 정량·정성 패턴

스토리보드의 평균 관찰 간격은 9.700초다. 자막 영역을 제외한 화면 상단 72%를 비교했을 때 인접 프레임의 평균 pHash 중앙값은 29.867이고, 강한 변화 비율은 97.09%, 근접 중복 비율은 0.92%였다. 자막 글자만 바뀌어 차이가 커진 결과가 아니라 주제·구도·화각이 실제로 바뀐 것이다.

공통된 시각 문법은 다음과 같다.

1. 화면 전체를 채우는 편집 일러스트를 사용한다. 빈 종이 위에 고립된 책·두루마리 카드가 기본형이 아니다.
2. 인물이 필요한 주장에는 인물과 행동을, 장소가 핵심인 주장에는 공간과 환경을 먼저 보여준다.
3. 지도는 이동·분포·거리·영역 관계가 핵심일 때만 사용한다.
4. 도식은 유전·해부·기후·지질처럼 눈에 보이지 않는 인과관계를 설명할 때만 사용한다.
5. 책·문서·유물·실험실은 연구 방법이나 증거 자체가 내레이션의 핵심일 때만 사용한다.
6. 발표자 캐릭터를 모든 장면에 넣지 않는다. 내레이션은 음성 중심이고 화면은 주장 중심이다.
7. 넓은 전경, 중간 행동, 세부 사물, 지도·도식, 분위기 리셋을 교차해 화면 크기와 정보 밀도를 바꾼다.
8. 읽을 수 있는 글자는 편집자가 의도적으로 올린 자막·도식 레이어다. 생성 모델의 임의 글자를 정보 전달에 사용하지 않는다.

## 5. EP02 현행 결과와의 차이

`full-v4-001`의 승인 대본은 18분 목표, 126문장, 공백 제외 약 3,477자다. 현행 플래너는 이를 63장으로 만들므로 한 장이 평균 17.14초를 담당한다. 이는 벤치마크 관찰 간격의 약 1.77배다.

역할 분포도 더 큰 문제다.

- `evidence_object`: 27장
- `host_explainer`: 13장
- 이 둘의 합: 40/63장, 63.5%
- 사물 중심 화면 최대 연속 길이: 8장
- 프롬프트 컴파일러의 증거 장면 기본 모티프: 책·두루마리·빈 종이·돌·나무 토큰 네 종류 순환
- 정책 재시도: 역사 인물과 행동을 제거하고 다시 책상 위 사물로 변환

따라서 모델이 같은 이미지를 고집한 것이 아니라 프로그램이 서로 다른 내레이션을 같은 의미의 프롬프트로 축약했다. 모델이나 계정을 바꿔도 이 계약을 그대로 사용하면 반복이 재현된다.

## 6. 프로그램에 적용할 벤치마크 규칙

### 6.1 샷 밀도

- 기본 프로필: 9~12초, 목표 10.5초
- 한 화면: 원칙적으로 1문장, 최대 2문장
- 12초를 넘는 단일 문장: 절·세그먼트 경계에서 두 시각 샷으로 나눈다.
- EP02 예상치: 95~120장
- 글자 수가 아니라 문장별 실제 TTS 시작·종료 시간을 기준으로 한다.

### 6.2 시각 모드

`event_reconstruction`, `place_establishing`, `route_map`, `mechanism_diagram`, `evidence_artifact`, `modern_analogy`, `atmosphere_transition`, `host_chapter_hinge`의 여덟 모드를 사용한다. 기존 다섯 `visual_role`은 하위 호환을 위해 이 모드에서 파생한다.

### 6.3 쉽선비 사용

- 전체의 8~12%
- 인트로·장 전환·핵심 요약에서만 사용
- 연속 최대 1장
- 쉽선비 장면 사이 최소 7개 비호스트 샷
- 생성 모델이 쉽선비를 그리지 않고 승인된 canonical overlay만 합성

### 6.4 다양성

- 같은 `visual_mode` 연속 최대 2장
- `evidence_artifact` 연속 최대 1장
- 같은 일반 소품 모티프는 10장 창에서 최대 2회
- `(모드, 주체, 행동, 장소, 화각, 소품)` novelty signature 완전 중복 0건
- 인접 이미지 pHash 6 이하이면 자동 실패

### 6.5 파일럿

기존의 분산 8장 파일럿만으로는 연속 붕괴를 찾을 수 없다. 다음 두 세트를 합친다.

- 콜드오픈 연속 파일럿: 첫 12장 또는 첫 120초
- 분산 커버리지 파일럿: 장·모드·인물·지도·도식·증거·쉽선비를 대표하는 8장

두 세트의 콘택트시트에 샷 ID, 시간, 내레이션 요약, 시각 모드, 핵심 앵커를 표시하고 둘 다 현재 해시로 승인된 후에만 전체 생성을 허용한다.

## 7. 결론

벤치마크의 핵심은 화풍 복제가 아니다. 성과가 높은 영상들은 **내레이션의 구체적 명제마다 다른 화면을 할당하고, 인물·행동·장소·메커니즘 중 무엇이 핵심인지 바꾸며, 약 10초 안에 시각적 질문을 갱신한다.** Human Archive가 우선 바꿔야 할 것은 모델·계정이 아니라 샷 분할 기준, 의미 브리프 계약, 프롬프트 컴파일러, 연속 파일럿과 다양성 게이트다.
